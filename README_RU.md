# SnowTouch 3.0

Интерактивные новогодние живые обои для Android.

## Возможности
- Новогодний зимний фон с наряженной ёлкой.
- Снегопад и накапливающиеся сугробы внизу экрана.
- Раздвигание снега пальцем с образованием боковых валиков.
- Подбрасывание снежной пыли быстрым движением.
- Встряхивание телефона рассыпает часть верхнего слоя сугробов.
- Упрощённые столкновения снежинок, передающие им импульс.
- Русское название и описание в системном выборе живых обоев.
- Собственная иконка приложения SnowTouch.

## Сборка
Проект использует Kotlin, Android SDK 35 и JDK 17. GitHub Actions собирает APK по push в ветку `main` или вручную через `workflow_dispatch`.

Готовый файл в артефактах Actions называется `SnowTouch.apk` (это debug-подписанная тестовая сборка; имя приложения на телефоне — SnowTouch).

## Установка обоев
Открой SnowTouch → «Установить живые обои» → «Установить обои» → выбери главный экран.
Чтобы убрать обои, открой системный выбор обоев Android и выбери другие обои или статичное изображение.
