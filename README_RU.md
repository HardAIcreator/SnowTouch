# Snow Touch — Android Live Wallpaper

Интерактивные живые обои с реалистичным процедурным снегом.

## Что внутри
- Нативный Android `WallpaperService` на Kotlin.
- 1500 частиц снега разного размера и скорости.
- Проведение пальцем отталкивает снежинки.
- Удержание пальца более 450 мс притягивает частицы.
- Тангенциальная сила добавляет эффект вихря.
- Рендеринг через Android Canvas, ограничение около 30 FPS.
- Пауза анимации, когда обои не видны.

## Сборка
Проект предназначен для Android Studio:
1. Распакуйте архив.
2. Откройте папку `SnowTouch` в Android Studio.
3. Дождитесь Gradle Sync. При необходимости установите Android SDK Platform 35 и JDK 17.
4. Нажмите Run для установки приложения на телефон.

Затем:
1. Откройте приложение Snow Touch.
2. Нажмите `SET LIVE WALLPAPER`.
3. В системном окне предварительного просмотра выберите `Set wallpaper`.
4. Выберите главный экран.

## Важно
Это исходный Android Studio проект, а не готовый APK. Для сборки APK нужен Android SDK/Android Studio.
Интерактивность касаний зависит от того, передаёт ли конкретный лаунчер события живым обоям.


## Сборка APK без компьютера (через GitHub)
В архив добавлен workflow `.github/workflows/android.yml`.
Если загрузить проект в GitHub-репозиторий, открыть вкладку **Actions** и запустить
**Build Snow Touch APK**, GitHub соберёт debug APK. Готовый файл появится в разделе
Artifacts у завершённого запуска. Для установки скачайте APK на телефон и откройте его.
